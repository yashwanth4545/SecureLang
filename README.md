# SecureLang

An enterprise-grade, security-focused programming language.

## Architecture

- **Frontend**: React, Vite, TailwindCSS
- **Backend API**: Node.js, Express, TypeScript
- **Engine/Compiler**: Rust
- **Database**: PostgreSQL

## Quick Start

1. Start the database:
   ```bash
   docker-compose up -d
   ```
2. Navigate to `/backend` and install dependencies.
3. Navigate to `/frontend` and install dependencies.
4. Navigate to `/securelang-engine` to build the compiler using `cargo build`.
